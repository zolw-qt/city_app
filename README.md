# Kraków Open Data: infrastruktura i demografia

Prototyp aplikacji webowej w Streamlit do poznawania miejskich danych Krakowa. Aplikacja prezentuje trendy demograficzne oraz rozmieszczenie przystanków i przedszkoli na interaktywnej mapie.

Dokumentacja techniczna znajduje się w `docs/DOKUMENTACJA_TECHNICZNA.md`. Osobna instrukcja uruchomienia dla odbiorcy projektu jest w pliku `INSTRUKCJA_URUCHOMIENIA.txt`.
